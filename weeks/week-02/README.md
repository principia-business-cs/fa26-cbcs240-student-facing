# Week 2 - Innovation Is Not a Waterfall

## Focus

Innovation is not a perfect plan that moves in a straight line.

This week we will practice the course loop:

> Goal -> Data -> Experiment -> Sensemaking -> Adjustment

## What You Will Do

- Compare linear planning with agile innovation.
- Revisit campus observations from Week 1.
- Identify assumptions inside early ideas.
- Ask what evidence would help you decide what to do next.
- Practice turning a rough idea into a small learning cycle.

## Key Question

What do we need to learn before we commit too strongly to a solution?

## Deliverable

Innovation Loop Case Notes
