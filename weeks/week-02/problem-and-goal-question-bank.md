# Problem and Goal Question Bank

Use these questions to help your group move from something you noticed to a clear problem statement and goal statement.

## 1. Start With What You Noticed

1. What exactly did we notice?
2. Where did we notice it?
3. When does it happen?
4. Who is involved?
5. Have we seen this once, or does it seem like a pattern?

## 2. Identify Who Is Affected

1. Who experiences this problem most directly?
2. Who is affected indirectly?
3. Who has to deal with it, fix it, avoid it, or work around it?
4. Are different groups affected differently?
5. Who might care enough for this to be worth improving?

## 3. Understand the Current Situation

1. What do people currently do when this happens?
2. What workaround do they use?
3. What makes the current situation frustrating, confusing, slow, expensive, stressful, unfair, or wasteful?
4. What might people have accepted as normal even though it could be improved?
5. What evidence do we already have?
6. What evidence do we still need?

## 4. Use "I Wonder If..." Questions

Use these to explore before judging.

1. I wonder if this happens more at certain times of day.
2. I wonder if this affects some students more than others.
3. I wonder if the real issue is information, access, time, cost, motivation, coordination, design, policy, or habit.
4. I wonder if people already have a workaround.
5. I wonder if technology would actually help.
6. I wonder if a non-technology solution would work better.
7. I wonder if fixing this would create a new problem.
8. I wonder if we are assuming the solution too early.

## 5. Use "Yes, And..." Builds

Use these to strengthen an idea.

1. Yes, and this could also affect people who...
2. Yes, and we could test that by...
3. Yes, and another version of the problem might be...
4. Yes, and another version of the goal might be...
5. Yes, and the first small prototype could be...
6. Yes, and we should also ask...

## 6. Define the Problem

1. What is the real problem underneath what we noticed?
2. Why does this problem matter?
3. What happens if nobody improves it?
4. Are we describing a problem or already jumping to a solution?
5. Can we state the problem without naming our favorite solution?

Problem statement template:

```text
[Group of people] need a better way to [do something / experience something] because [reason it matters].
```

## 7. Define the Goal

1. What would be better if this problem improved?
2. What should people be able to do more easily?
3. What should become faster, clearer, safer, cheaper, more welcoming, or less stressful?
4. What would count as progress?
5. How would we know the situation improved?
6. Is the goal open enough that more than one solution is possible?

Goal statement template:

```text
Our goal is to help [group of people] [achieve outcome] so that [larger benefit].
```

## 8. Choose a First Small Test

1. What do we need to learn before building anything?
2. Who could we interview?
3. What could we observe?
4. What assumption could we test quickly?
5. What small prototype, sketch, survey, or comparison could help us learn?

First-test template:

```text
We will test whether [assumption] by [small action] with [people/context].
```
